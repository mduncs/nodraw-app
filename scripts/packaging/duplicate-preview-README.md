# NoDraw Duplicate Preview

Open **NoDraw Duplicate Preview.app**. It is independent of the installed app and the earlier Editor Preview.

Choose **Duplicates** under Triage in the sidebar, then **Scan library**. The bundled procedural sample includes a three-copy mint image group and a two-copy cyan group with different source notes.

Compare the media and notes. Select one or several **Keep** checkboxes, then use **Keep N, move M**. Unselected whole items go to Recently Deleted; files, notes, edits and references remain intact. No files are permanently deleted and no disk space is reclaimed here. **History** provides Undo/Redo. **Keep all**, **Not duplicates**, and **Later** are separate decisions retained across scans.

Exact copies means every declared media file matches in full. Source screenshots, notes and edits may differ. Look-alikes are bounded thumbnail comparisons, not proof of identity; some matches can be missed.

The first scan reads every media file. Later scans cache file versions and digests; review rechecks the chosen group before committing. Cancel retains the last completed results.

The preview uses `~/Library/Application Support/NoDraw Duplicate Preview/{Archive,AppSupport}`. It starts with its own 17-item sample library, suppresses enrichment/models and the download server, and does not change your normal archive, installed app, or Editor Preview. Drop local media into this preview to try imports. “Import another copy” is explicit; unchanged repeated imports otherwise skip.

Browser capture prevention changes are separate source changes; this app bundle does not update the installed browser extension or running server.
